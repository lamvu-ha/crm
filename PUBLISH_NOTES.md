# Published source

This snapshot excludes local customer data, employee account files, chat history, logs, generated hosting packages and builds. Embedded initial passwords and Firebase API keys have been replaced with placeholders. Configure your own Firebase project and private JWT/refresh secrets before using the main application; replace the seed password placeholders before creating initial accounts. The isolated demo contains synthetic accounts only.

Validation before publication: TypeScript checks passed for both applications, 260/260 audit cases passed, workflow tests and demo render passed, both builds passed.
