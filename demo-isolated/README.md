# CRM demo độc lập

Chạy từ thư mục này: `npm run dev`. Mở http://127.0.0.1:3001.

Tài khoản: admin, manager, sale01, sale02. Mật khẩu chung: Demo@2026!

Dữ liệu giả lập chỉ lưu trong thư mục này. Firestore, Google, Gmail và Gemini bị tắt. Đây vẫn là bản demo chạy local, không triển khai công khai. Dùng node_modules ở thư mục cha; không cần cài lại.
